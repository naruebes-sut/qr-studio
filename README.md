# QR Studio

A modern, responsive QR Code Generator that runs entirely in the browser.

## Features

- Generate QR codes from text or URLs
- Live preview
- 180, 256, 320, and 512 px output sizes
- QR error-correction levels L/M/Q/H
- Custom foreground and background colors
- Download QR code as PNG
- Responsive mobile-friendly interface
- No backend and no data upload

## Run

Open `index.html` in a browser.

The project uses [QRCode.js](https://github.com/davidshimjs/qrcodejs) from jsDelivr, so an internet connection is needed to load the QR generation library.
